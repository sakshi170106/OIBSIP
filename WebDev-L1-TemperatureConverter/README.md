# Temperature Converter — OIBSIP Task 3

An interactive temperature conversion website created for the Oasis Infobyte Web Development & Designing internship.

## Features

- Numeric temperature input with validation
- Celsius, Fahrenheit and Kelvin input-unit selector
- Converts and displays all three units simultaneously
- Convert button for calculation
- Clear result labels and values
- Absolute-zero validation
- User-friendly error and success messages
- Responsive desktop and mobile layout

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## How to Run

1. Open `index.html` in a browser.
2. Enter a temperature value.
3. Select Celsius, Fahrenheit or Kelvin.
4. Click **Convert Temperature**.
5. View all converted values.

## Validation

The application rejects non-numeric/empty input and values below absolute zero.
