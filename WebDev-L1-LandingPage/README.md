
# CodeCraft Academy — Landing Page

A modern and responsive landing page for CodeCraft Academy, designed to showcase web development learning, practical projects, and skill-building opportunities.

## 🚀 Project Overview

CodeCraft Academy is a clean and responsive educational landing page built using HTML5 and CSS3.

The website provides sections for courses, features, about information, call-to-action, contact details, and footer navigation.

## ✨ Features

- Sticky/Fixed navigation bar
- Responsive design for desktop and mobile
- Hero section with headline, subheadline and CTA buttons
- Features section
- Courses section
- About section
- Call-to-action section
- Contact section with form
- Footer with navigation and social links
- Consistent colour palette
- Clean typography
- CSS Flexbox and Grid layout
- Mobile-friendly design

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Flexbox
- CSS Grid
